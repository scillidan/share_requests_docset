# share_requests_docset

[![Release](https://github.com/scillidan/share_requests_docset/actions/workflows/release.yml/badge.svg)](https://github.com/scillidan/share_requests_docset/actions/workflows/release.yml)

This repo is for generating docset files from [psf/requests](https://github.com/psf/requests). For using in [Zeal](https://zealdocs.org), [Dash](http://kapeli.com/dash), [Velocity](https://velocity.silverlakesoftware.com/) ...

## Usage

- Zeal → Tools → Docsets → Add feed
	- `https://raw.githubusercontent.com/scillidan/share_requests_docset/refs/heads/main/Requests.xml`
